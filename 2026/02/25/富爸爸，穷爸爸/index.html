《富爸爸，穷爸爸》读书笔记

这是很好的理财启蒙书籍，教授如何转化思维方式，传授的主要思想是：穷人和中产阶级为钱工作，而富人则让钱为他们工作！！！

人们在财务困境中挣扎的主要原因是：他们在学校里学习多年，却没有学到任何关于金钱方面的知识。其结果是，人们只知道为金钱而工作……但从来不学着让金钱为自己工作。

故事的主角罗伯特·清崎有两个爸爸形象：

  • 穷爸爸：是他的亲生父亲，一位拥有高学历的政府教育官员。他的人生信条是“好好学习，找个好工作，稳定地往上爬”。他一生为债务所困，去世后留下的是一堆待付的账单。

  • 富爸爸：是他好朋友的父亲，连初中都没念完，但却是成功的企业家和投资家。他的人生信条是“学习如何让钱生钱”。他最终成为夏威夷最富有的人之一，为家人和慈善事业留下了数千万美元的遗产。

年幼的清崎在两个爸爸完全相反的教导中，选择了跟随“富爸爸”学习金钱的运作规律，最终走上了财务自由之路。

分清资产与负债

富爸爸认为，要变得富有，首先必须在头脑中搞清楚资产和负债的区别，并不断地买入资产。

  • 资产：就是把钱放进你口袋里的东西。比如，能收租的房产、分红的股票、有稳定盈利的生意、可以让别人经营而你只负责投资的业务等。

  • 负债：就是把钱从你口袋里拿走的东西。比如，自住的房子（要还房贷、交物业费）、车子（要加油、保养、保险）、信用卡账单等。

富人的秘密：富人不断地买入资产，让资产产生的现金流（被动收入）去覆盖日常支出，甚至再去购买新的资产。这样，资产像滚雪球一样越滚越大，他们即使不工作也能越来越富。

穷人和中产阶级的困境：他们有了收入后，往往会先买下一堆以为是“资产”的负债。比如，升职加薪后，贷款买更大的房子、更好的车。这些负债会不断地从他们口袋里掏钱，导致他们不得不更努力地工作来支付账单，陷入一个”起床-上班-付账-再上班”的恶性循环。作者将这种模式称为 “老鼠赛跑” 。

通往财务自由的六堂课

书中将富爸爸的智慧总结为六个核心课程：

1. 富人不为钱工作

穷人和中产阶级为钱而工作。富人让钱为他工作

大部分人都陷入了“老鼠赛跑模式”，起床，上班，付账，再起床，再上班，再付账……他们的生活，永远被这两种感觉所控制：恐惧和贪婪。给他们更多的钱，他们就会以更高的开支重复这种循环。人们的生活永远被这两种感觉控制：恐惧和贪婪。

富爸爸希望去研究钱的运动规律，好让钱为我所用。

如果害怕没钱而立刻接受一份工作，就会像老鼠赛跑一样陷入为钱工作的陷阱。真正的学习是让恐惧和贪婪驱使你思考，而不是让你陷入工作的死循环。

2. 为什么要教授财务知识

富人买入资产。穷人只有支出。中产阶级购买自以为是资产的负债。

重要的不是你挣了多少钱，而是你能留下多少钱。

必须能分清资产和负债，并不断地买入资产。这也是为什么很多高薪的专业人士（如医生、律师）依然财务紧张的原因——他们缺乏财商，把负债当成了资产。

当你的资产项能产生足够的收入来填补你的支出时，你就是富有的，即使你还没有什么钱。

3. 关注自己的事业

富人关心的焦点是资产而其他人关心的是收入。

在保住日常工作（职业）的同时，要开始建立并关注自己的事业（资产项）。事业的重心是你的资产，而不是你的收入。比如，你可以一边工作，一边开始投资房地产或小生意。

什么是资产：

  1. 不需我到场就可以正常运作的业务。我拥有它们，但由别人经营和管理
  2. 股票
  3. 债券
  4. 能够产生收入的房地产
  5. 票据（借据）
  6. 版税，如音乐、手稿、专利
  7. 其他任何有价值、可产生收入或有增值潜力并且有很好销路的东西”

4. 税收的历史和公司的力量

富人永远不会缴税。

富人利用公司等法律实体来合理避税。他们赚钱 -> 花在开销 -> 再纳税（通过公司支出享受税收优惠）；而普通人则是赚钱 -> 纳税 -> 再花在开销上。富人的逻辑是，让钱通过合法的公司结构，为自己创造更大的现金流。

财商是由4个方面的专门知识构成

  1. 会计：会计就是财务知识或解读数字的能力。如果你想建立一个自己的商业帝国，财务知识是非常重要的。你管理的钱越多，就越要精确，否则这幢大厦就会倒塌。这需要左脑来处理，是细节的部分。财务知识能帮助你读懂财务报表，还能让你辨别一项生意的优势和劣势。

  2. 投资：投资是钱生钱的科学。投资涉及策略和方案，这要右脑来做，是属于创造的部分。

  3. 了解市场：了解市场是供给与需求的科学。这要求了解受感情驱动的市场的“技术面”。市场的另一个因素是“基本面”，或者说是一项投资的经济意义。一项投资究竟有无意义最终取决于当前的市场状况。”

  4. 法律：利用一个具有会计、投资和市场运营的企业会使你的财富实现爆炸性地增长。了解减税优惠政策和公司法的人会比雇员和小业主更快致富。这就像一个人在走，而另一个人却在飞，久而久之这种差距就更大了。

5. 富人的投资

在现实生活中，人们往往是依靠勇气而不是智慧去取得领先的位置的

要学习如何管理风险，而不是一味地害怕风险。富人会寻找别人忽视的机会，通过财务知识去发现价值，并勇敢地去投资。他们明白，不敢冒险才是最大的风险。

风险无处不在，要学会驾驭风险，别总想回避风险。

如果你清楚自己在做什么，那就不是在赌博；如果你把钱投进一笔交易然后只是祈祷，这才是在赌博。

一般有两种类型的投资者：
（1）进行一揽子投资的人（比如财务计划师）；
（2）自己创造投资机会的人（职业投资者）。

6. 学会不为钱工作

精通专业技能既是优势也是弱点

工人付出最大努力以免于被解雇，而雇主提供最低工资以防止工人辞职

不要只为了一份安稳的薪水而工作。要不断学习，特别是市场营销、销售、管理等综合技能。有时候，学习新技能比赚多少钱更重要，这能让你在机会来临时抓住它。

开始行动

如何开始行动？

  1. 找一个超现实的理由——精神的力量：找到你内心渴望致富的强大理由，比如想给家人更好的生活、想实现某个梦想。

  2. 每天做出选择——选择的力量：把时间花在学习投资、学习新技能上。

  3. 慎重地选择朋友——关系的力量：多和那些有富人思维、有正能量的人交流，从他们那里获取信息和动力。不要听贫穷或者胆小的人的话，因为他们过的是“小鸡式”的生活

  4. 掌握一种模式，然后再学习一种新的模式—快速学习的力量：行动起来，哪怕从小的投资开始，在实践中学到的东西远比书本上的理论重要。

  5. 首先支付自己—自律的力量

  6. 给你的经纪人以优厚的报酬—好建议的力量：好的信息是无价的，他们值得

  7. 做一个印第安给予者—无私的力量：我要多久才能收回投资？

  8. 用资产来购买奢侈品—专注的力量

  9. 对英雄的崇拜—神话的力量：模仿英雄，挖掘自身的巨大潜能

  10. 先予后取—给予的力量：如果你想学习有关金钱的知识，那就要先告诉别人你赚钱的方法，然后新的思想和绝妙的灵感就会喷涌而出。

最后

在会计领域里，有三种不同的收入：

  1. 劳动性收入。
  2. 投资组合收入。
  3. 被动收入。

劳动性收入是你工作得来的钱，而被动收入和投资组合收入则是为你工作的钱。

变富有的关键是拥有尽快将劳动性收入转换成被动收入或投资组合收入的能力

劳动性收入的税赋是最重的，而税赋最轻的收入则是被动收入。这也是为什么你要让金钱为你努力工作的另一个原因。政府从你努力工作所得的收入中收的税比你的金钱为你努力工作所得的收入所收的税还高。
